# Obsidian录音转文字

将手机录音文件转为文字并保存为 Obsidian 笔记。

## 功能

- 🎤 一键选择音频文件，自动转写成文字
- 📝 每天自动生成一篇笔记，同一天多条录音汇总在一起
- ☁️ 支持 .wav/.mp3/.m4a/.mp4 等常见音频格式
- ⏱️ 单次音频不超过 5 分钟
- 🔒 使用你自己的阿里云 API Key，数据安全可控

## 使用

1. 在插件设置中填写阿里云百炼 API Key 和你的中转服务器地址
2. 点击左侧 🎤 按钮，选择音频文件（不超过 5 分钟）
3. 等待 10-60 秒，转写完成自动追加到今日笔记

详细部署教程：[使用手册](https://github.com/jiangwenping0570/obsidian-recorder-transcriber)
